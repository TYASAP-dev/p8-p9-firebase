# Login Firebase & Push Notification (FCM)

Aplikasi Flutter untuk autentikasi pengguna menggunakan **Firebase Authentication (Email/Password)** dan penerimaan notifikasi menggunakan **Firebase Cloud Messaging (FCM)** serta **Flutter Local Notifications** pada kondisi *Foreground*, *Background*, dan *Terminated*.

## Cara Menjalankan
1. Jalankan `flutter pub get`
2. Pastikan file `lib/firebase_options.dart` dan `android/app/google-services.json` sudah terkonfigurasi.
3. Jalankan `flutter run` pada perangkat Android.
